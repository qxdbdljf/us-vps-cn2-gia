## 500G 月流量用完会怎样

500G 摊到 30 天，平均每天约 16G。这个配额对个人博客、API 接口、轻量爬虫是宽松的，对视频中转、大文件下载、图床这类业务是紧张的，几小时就能吃光。

美国 VPS 的通行做法是流量计费用完即限速，通常降到 1Mbps 上下，次月 1 日重置，限速期间机器仍然在线、SSH 能连，但网页基本打不开。AkkoCloud 页面上没有公开写明超额后的具体限速值和重置规则，这一点必须在下单前问客服确认，别默认它和别家一样。

## CN2 GIA、AS9929、CMIN2、AS4837 分别适合谁

这些名词背后是不同的回国路径，选错线路比选错配置更影响体验。

- **CN2 GIA**：电信的精品承载网，回国路径短、晚高峰相对稳定，价格也最贵。电信宽带用户体验最好，联通、移动用户走这条线通常也不差，但具体到某一台机器要看回程路由。
- **AS9929**：联通的精品网，常被叫作“联通版 GIA”，三网回程比较均衡，是近年性价比较高的选择。
- **CMIN2 / CMI**：移动的精品与国际出口线路，移动宽带用户优先看这个。
- **AS4837**：联通普通国际线路，价格低，晚高峰会有波动，适合预算优先、能接受偶尔卡顿的场景。
- **普通国际 BGP**：走 Cogent、Telia、HE 这类国际互联，最便宜，国内高峰期容易抖，适合纯海外访问或做中转落地。

一个粗略的对应关系：电信用户看 CN2 GIA 和 163，联通用户看 4837 和 9929，移动用户看 CMI 和 CMIN2。买之前先搞清楚自己家宽带是哪家、出口走的哪条，再去对线路，比看商家宣传语有用。

AkkoCloud 全线标的是 CN2 GIA，对电信方向最友好。联通、移动的回程它没有逐条公示，官网上也没写三网优化细节。想验证很简单，官方提供了 Looking Glass（sjclg.akkocloud.com）和测试 IP **45.9.10.146**，买之前先 ping、先 traceroute，自己的网络环境测得的结果才算数。

## 原生 IP 和 DNS 解锁不是一回事

AkkoCloud 美国页面对 IP 的表述是“分配美国原生 IP，或提供 DNS 解锁美国地区流媒体服务（Netflix、Disney+ 等）”。这两条并列写在一起，实际差别很大。

原生 IP 指的是这台机器分到的 IPv4 归属在美国、由 ARIN 之类的区域注册机构分配，不是从别处广播过来的段。它对注册美区账号、访问对 IP 归属敏感的服务更有利。DNS 解锁则是把流媒体的域名解析转到另一台机器上，你本机的 IP 没变，只是让播放器认为你在美国。前者是身份，后者是绕路。

如果你买机器主要是为了用 ChatGPT、Claude 这类服务，注意官网并没有承诺这些能直接访问，只写了流媒体解锁。AI 服务对 IP 的风控更新很快，同一个段今天能用、下周可能就被拦，买之前最好找客服确认当前情况，或者用月付先试一个月。
